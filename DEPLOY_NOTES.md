# Upload and release guidance

GitHub repository: `altaqawy/rawnak-academy` (proposed).

Prefer a private repository until the backend and account security have been reviewed. Do not commit any Cloudflare D1, Supabase, Rawnak Group, or payment credentials.

For static preview hosting, upload `index.html` and `assets/` to a static host. Test desktop and 390px mobile and network image loads first. The repo contains the approved demo only, not the currently deployed production app.
